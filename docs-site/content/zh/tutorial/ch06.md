# 智能体系统

> **先给小白的一句话**：`AgentLoop` 就像**一位极有耐心的接线员**——它一遍遍拨打模型这通"电话"（`LLM.complete`），每次通话里可能让助手打好几个"内部转接"（工具调用 step）。电话打不通或卡住时，它按**有限次数**重试：没人接（空响应）试 2 次、通话卡壳（流停滞）续 1 次、对方占线要"等一下再打"（配额 429）最多等 2 次——所有重试都**有上限**，绝不让一个坏对话永远循环下去。

智能体（Agent）是 AIH 的核心运行单元。`AgentLoop` 驱动模型请求、工具调用和错误重试的完整循环。

## AgentLoop：turn/step 执行循环

`AgentLoop`（`core/src/agent-loop.ts`）采用 **turn/step** 两层循环：

- **Turn**：模型的一次完整响应（可能包含多个工具调用）。
- **Step**：turn 内的单次工具执行。

循环内置多层容错：

- `MAX_EMPTY_RETRIES = 2`：模型返回空响应时重试次数上限。
- `MAX_STALL_RESUMES = 1`：流式传输停滞后的恢复次数上限。
- `MAX_QUOTA_WAITS = 2`：配额不足（429）时等待重试次数上限。

此外还有 **流式停滞恢复**（stream-stall resume）和 **配额等待重发**（quota 429 wait-then-reissue）机制。

## 从源码看容错重试：三次"拨不通"的兜底

这些重试**数字**不是拍脑袋定的，而是 `core/src/agent-loop.ts` 里显式的常量，且**每一种都有上限**：

```ts
/** 空响应（无文本也无工具调用）时，念叨模型重试的次数上限。 */
const MAX_EMPTY_RETRIES = 2;
/** CC#49 — 每次 turn 流停滞续接次数上限（防止病态网络永远循环）。 */
const MAX_STALL_RESUMES = 1;
/** CC#51 — 配额用尽（429）自动续接次数上限。 */
const MAX_QUOTA_WAITS = 2;
```

真正的兜底动作发生在 turn 的 step 循环里（`while (steps < this.#maxSteps ...)`），层层 `try/catch`：

```ts
try {
  response = await doComplete();          // 拨打"模型电话"
} catch (err) {
  if (ac.signal.aborted) break;           // 用户主动取消 → 直接放手
  if (err instanceof StallError && stallResumes < MAX_STALL_RESUMES) {
    stallResumes += 1;                    // 流停滞但已吐出部分文字
    this.#log.append({ type: "assistant/message", turnId, text: partial }); // 先保住已产出的部分
    continue;                             // 加一句"请继续说完"，下一轮接着来
  }
  if (err instanceof QuotaError && hooks?.quotaWait && quotaWaits < MAX_QUOTA_WAITS) {
    quotaWaits += 1;                      // 配额耗尽：等重置时间到了再重发
    await sleepMs(waitSec * 1000, ac.signal); // 源注释：这是「重发同一被拒的调用」
    continue;                             // 而不是重跑整个 turn
  }
}
```

三个设计要点：

1. **有界重试**：`MAX_*_WAITS/RETRIES` 全是小整数，从根上杜绝"坏对话无限循环烧 token"（这正是 loop 防跑飞的关键）。
2. **保住既有成果**：流停滞时把已吐出的 `partialText` 先写入日志，再让模型"接着说完"，而不是整段重来。
3. **重发而不是重跑**：配额耗尽时重发**同一个**被拒的调用（源注释明说 not re-run the turn），避免无谓地重复执行工具产生副作用。

## Build / Plan 双模式

AgentLoop 支持两种工作模式：

- **Build 模式**：所有工具可用，包括写操作。
- **Plan 模式**：隐藏写工具，仅允许只读操作，适合规划阶段。

通过 Tab 键或 `/mode build` 命令切换模式。

## 扩展点（Seams）

AgentLoop 通过丰富的扩展点实现可定制性：

- **systemPrompt**：自定义系统提示词。
- **observers**（`LoopObserver`）：监听 `onTurnStart`、`onTurnEnd`、`onModelResponse`、`onToolCall`、`onToolResult`、`onCompaction` 事件。`LoopAbort` 可中断当前 turn。
- **onPromptInput**：调试用输入钩子。
- **compactContext**：自定义压缩策略。
- **budget/costOf**：自定义预算与成本计算。
- **sensors**：运行时传感器。
- **onEscalate**：升级处理钩子。

## 子智能体

AIH 支持多种子智能体形态：

- **task**：串行执行，拥有独立上下文，适合分解子任务。
- **best_of_n**：并行运行 N 个候选 + 裁判选优，适合高风险决策（参见 [第 7 章](ch07) 关于模型适配的说明）。
- **teams**：多智能体协作团队。
