# 智能体系统

智能体（Agent）是 AIH 的核心运行单元。`AgentLoop` 驱动模型请求、工具调用和错误重试的完整循环。

## AgentLoop：turn/step 执行循环

`AgentLoop`（`core/src/agent-loop.ts`）采用 **turn/step** 两层循环：

- **Turn**：模型的一次完整响应（可能包含多个工具调用）。
- **Step**：turn 内的单次工具执行。

循环内置多层容错：

- `MAX_EMPTY_RETRIES = 2`：模型返回空响应时重试次数上限。
- `MAX_STALL_RESUMES = 1`：流式传输停滞后的恢复次数上限。
- `MAX_QUOTA_WAITS = 2`：配额不足（429）时等待重试次数上限。

此外还有 **流式停滞恢复**（stream-stall resume）和 **配额等待重发**（quota 429 wait-then-reissue）机制。

## Build / Plan 双模式

AgentLoop 支持两种工作模式：

- **Build 模式**：所有工具可用，包括写操作。
- **Plan 模式**：隐藏写工具，仅允许只读操作，适合规划阶段。

通过 Tab 键或 `/mode build` 命令切换模式。

## 扩展点（Seams）

AgentLoop 通过丰富的扩展点实现可定制性：

- **systemPrompt**：自定义系统提示词。
- **observers**（`LoopObserver`）：监听 `onTurnStart`、`onTurnEnd`、`onModelResponse`、`onToolCall`、`onToolResult`、`onCompaction` 事件。`LoopAbort` 可中断当前 turn。
- **onPromptInput**：调试用输入钩子。
- **compactContext**：自定义压缩策略。
- **budget/costOf**：自定义预算与成本计算。
- **sensors**：运行时传感器。
- **onEscalate**：升级处理钩子。

## 子智能体

AIH 支持多种子智能体形态：

- **task**：串行执行，拥有独立上下文，适合分解子任务。
- **best_of_n**：并行运行 N 个候选 + 裁判选优，适合高风险决策（参见 (ch07) 关于模型适配的说明）。
- **teams**：多智能体协作团队。
