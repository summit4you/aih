# 项目结构与开发环境

## Monorepo 全景

AIH 采用 npm workspaces 管理的 monorepo，`package.json` 声明了三个工作区：`core`、`mcp-server`、`cli`。根目录一览：

```
aih/
├── core/            # L1 内核（agent-loop / tool-registry / session-log / seams / prompts）
├── cli/             # CLI + TUI + 本地工具（dev-tools / general-tools / gate / config）
├── mcp-server/      # L0 接入层（app-adapter / todo-app 示例）
├── docs-site/       # 文档站（独立包，marked 单依赖）
├── scripts/         # doctor / check / eval / install / package 脚本
├── evals/           # 评测用例
├── examples/        # 示例项目
├── skills/          # 内置技能（SKILL.md）
├── tasks/           # 任务简报
├── docs/            # 内部设计文档（roadmap / decisions / parity-matrix）
├── aih.json         # 运行时配置
├── harness.yml      # 声明式 harness 配置
├── APP.md           # 应用智能体操作契约（唯一事实源）
├── start.sh         # 本地启动脚本（opencode Zen 免费网关）
└── package.json     # 根 package（workspaces + scripts）
```

## 从源码开始：环境搭建

前提条件：**Node.js ≥ 20**。克隆仓库后依次运行：

```sh
git clone https://github.com/summit4you/aih && cd aih
npm run bootstrap   # 安装所有工作区依赖
npm run doctor      # 环境就绪检查
npm run check       # tsc 构建 + 契约一致性校验
npm test            # 冒烟测试：core/dist/smoke.js → mcp-server/dist/smoke.js → cli/dist/smoke.js
npm run eval        # 完整交接门禁（doctor + bootstrap + check + test 串联）
```

快速验证安装是否成功：

```sh
npm run cli -- run "add a todo buy milk" --mock   # --mock 离线演示，无需 API key
```

## core/src — L1 内核

`core/` 是 AIH 的心脏，不依赖任何业务逻辑，也不包含 CLI 或 TUI 代码。关键文件：

| 文件 | 职责 |
|---|---|
| `agent-loop.ts` | AgentLoop 驱动一轮多步执行，turn/step 循环、build/plan 双模式、Goal 裁判 |
| `tool-registry.ts` | ToolRegistry 守卫管线：工具注册 + 权限门 + 钩子（脱敏/计时/审计）+ 并行只读调度 |
| `session-log.ts` | SessionLog append-only JSONL 事件流，支持分叉/checkpoint/restore 回滚 |
| `seams/` | 可替换接缝接口（LLM 适配器、沙箱、审批门、技能加载器等） |
| `prompts.ts` | 系统提示词模板（含 Goal 守卫规则） |
| `budget.ts` | Token 预算与成本跟踪 |
| `types.ts` | 核心类型定义（Event、Tool、Action、Context 等） |

## cli/src — CLI + TUI + 本地工具

`cli/` 是用户直接交互的层面，文件众多，重点文件：

| 文件 | 职责 |
|---|---|
| `index.ts` | CLI 入口：命令解析、子命令分发（run / chat / tools / serve / attach 等） |
| `tui.ts` | opencode 风格交互终端：输入渲染、diff 展示、状态栏 |
| `config.ts` | 配置加载与合并（aih.json / env / CLI flags） |
| `gate.ts` | 审批门：allow/ask/deny 路由、run-or-copy 批准 |
| `general-tools.ts` | 通用工具集（read_file / write_file / edit / grep / glob / websearch 等） |
| `dev-tools.ts` | 开发者工具（shell_context / error-detect / question 等） |
| `sandbox.ts` | 沙箱执行后端（local / bwrap / remote） |
| `skills.ts` | 技能加载器（SKILL.md 三级加载 + BM25 建议） |

## mcp-server/src — L0 接入层

`mcp-server/` 把 `AppAdapter` 暴露为 MCP 服务器，仅三个源文件：

| 文件 | 职责 |
|---|---|
| `app-adapter.ts` | AppAdapter 实现：descriptor + context(query) + actions（用 zod 定义参数） |
| `index.ts` | MCP 服务器启动：注册 adapter 的 Context/Action/Event 为 MCP tools/resources |
| `smoke.ts` | 冒烟测试 |

`app-adapter.ts` 是理解 L0 契约的最佳入口——它定义了一个 todo-app 的完整接入，可作为你实现自己应用适配器的模板。

## 开发工作流速查

| 命令 | 用途 |
|---|---|
| `npm run bootstrap` | 安装依赖 |
| `npm run doctor` | 环境检查 |
| `npm run check` | 构建 + 校验 |
| `npm test` | 冒烟测试 |
| `npm run eval` | 完整门禁（CI 用） |
| `npm run bench` | AIH vs opencode 性能基准 |
| `npm run cli -- <cmd>` | 直接调用 CLI |
