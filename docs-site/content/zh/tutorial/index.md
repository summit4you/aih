# 导读：写给新读者的入门书

本书是一本 **AIH（App Intelligence Harness）** 的入门教程，同时又是一次**逐章深入源码**
的深挖。结构上借鉴 [opencodebook.xyz](https://www.opencodebook.xyz/)——那本书以"五部分、十八章"
的方式拆解 OpenCode 的架构与实现；我们把同样的骨架套在 AIH 上，逐章落到 AIH 真实的
代码、机制与设计决策。

> 阅读前提：不需要太深的背景。第 I 部分完全面向新手；进入第 II 部分前，建议先跟着
> [快速开始](../quickstart) 亲手跑一遍 AIH（`aih` 或 `aih run ... --mock`）。源码引用都以
> 仓库内相对路径给出，你可以随时打开对应文件对照。

- **想做平台接入**：读 [第 3 章](ch03) → [第 8 章](ch08) → [第 17 章](ch17)。

- **想改/扩展源码**：[第 2 章](ch02) + [第 4–7 章](ch04) + [第 13–14 章](ch13)。

## 关于源码引用的说明

仓库是一个 TypeScript monorepo，核心在 `core/src/`、CLI 在 `cli/src/`、接入层在
`mcp-server/src/`。源码深挖章节以**真实文件路径 + 关键标识符**为准，讲机制背后的"为什么"，
而不是罗列每一行。每个概念都尽量给一个可运行或可验证的落点。
