# MCP 与接入形态

AIH 支持多种接入形态，从 MCP 外部服务到 CLI 命令行再到嵌入式 SDK，适配不同的使用场景。

## L0 AppAdapter 契约

`AppAdapter`（`mcp-server/src/app-adapter.ts`）是 AIH 与外部应用集成的核心契约，由三部分组成：

- **descriptor**：应用描述信息。
- **context(query)**：根据查询返回当前上下文。
- **actions**：一组操作定义，每个 action 包含 `kind`（read/write）、`permission`（allow/ask/deny）、`parameters`（Zod Schema）和 `run` 执行函数。

`APP.md` 是 AppAdapter 的事实来源文档。以 `TodoAppAdapter` 为例，它实现了 Todo 应用的完整读写操作。

## 三种接入形态

### MCP 外部服务

将 `mcp-server/dist/index.js` 挂载到 opencode、codex 或 claude 等外部客户端，通过 MCP 协议交互。适合已有 AI 编程工具的团队。

### CLI 命令行

直接使用 `aih`、`aih run` 或 `aih chat` 启动交互。这是最简单的入门方式，参见 (ch07) 了解模型配置。

### 嵌入式 SDK

使用 `@aih/core` 包中的 `AgentLoop` 和 `ToolRegistry`，以编程方式构建智能体：

```typescript
const registry = new ToolRegistry();
registry.register({ name, description, kind, permission, run });
// 将 registry 传入 AgentLoop
```

适合需要深度定制的场景。

## 写操作确认机制

AIH 对写操作设置了安全确认：在 TTY 终端下提示 `[y/N]` 确认；在非 TTY 环境（如 CI）下必须传入 `--yes` 参数才能执行。详见 (ch05) 了解工具守卫管道。

| 形态 | 适用场景 | 入口 |
|------|----------|------|
| MCP 外部服务 | 已有 AI 编程工具 | `mcp-server/dist/index.js` |
| CLI 命令行 | 快速交互与脚本 | `aih` / `aih run` / `aih chat` |
| 嵌入式 SDK | 深度定制集成 | `@aih/core` |
