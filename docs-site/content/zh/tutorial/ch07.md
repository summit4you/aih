# Provider 多模型适配层

AIH 通过统一的 Provider 层适配多种大语言模型，使上层逻辑无需关心具体后端差异。

## LLMAdapter 接口

LLM 适配的核心接口定义在 `core/src/seams/llm.ts`（`LLMAdapter`）。主要实现包括：

- **llm-openai.ts**：兼容 OpenAI 协议，支持 SSE 流式传输和自动重试。
- **llm-sse.ts**：底层 SSE 工具函数——`consumeSSEStream` 消费流、`parseFrame` 解析帧、`StallError` 表示流停滞、`classifyProviderError` 分类错误类型。

## 模型解析流程

模型配置通过 `cli/src/config.ts` 中的 `resolveLlm` 和 `loadModelCatalog` 解析，按优先级读取：

1. 环境变量 `AIH_API_KEY`（API 密钥）、`AIH_MODEL`（模型名）、`AIH_BASE_URL`（接口地址）。
2. 配置文件中的对应字段。
3. 使用 `--mock` 参数进入离线模拟模式。

## 模型元数据

`cli/src/model-metadata.ts` 维护了来自 models.dev 的模型快照数据，包含各模型的上下文窗口大小、能力标签等信息。Provider 列表也在此模块中管理。

## 成本与速率追踪

`cli/src/cost.ts` 提供完整的成本和速率分析：

- **DEFAULT_PRICES**：各模型的默认定价。
- **resolvePrice**：解析特定模型的价格。
- **costForUsage**：根据实际 token 使用量计算成本。
- **aggregateUsage**：汇总多轮使用量。
- **tokensPerSecond**：计算模型响应速率（TPS）。

这些指标在 TUI 的 Context 面板中实时展示，也可通过 `/usage` 命令或 `aih stats` 查看。更多会话相关信息请参阅 (ch04)。
