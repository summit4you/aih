# 工具系统

AIH 的工具系统是智能体与外部世界交互的桥梁。所有工具通过 `ToolRegistry` 统一注册、查找和调用。

## ToolRegistry 与 ToolDefinition

`ToolRegistry`（`core/src/tool-registry.ts`）提供 `register`、`get`、`schemas` 和 `invoke` 四个核心方法。每个工具是一个 `ToolDefinition` 对象，包含：

- **name**：工具名称
- **description**：功能描述（供模型理解）
- **parameters**：参数 Schema
- **kind**：读/写类型
- **permission**：权限策略（静态字符串或动态函数）
- **execute**：实际执行逻辑

调用 `schemas()` 返回 `ToolSchema` 数组，供模型选择工具时使用。

## 守卫管道

每次调用工具时，`invoke()` 会经过五层守卫：

1. **权限解析**：将 `def.permission`（静态字符串或函数）解析为允许/拒绝。拒绝则返回 denied。
2. **死循环检测**：相同调用重复出现时触发——`DOOM_LOOP_ASK_AT = 3` 时要求用户确认，`DOOM_LOOP_DENY_AT = 6` 时硬拒绝。
3. **前置钩子**：执行脱敏、计时和审计；如果触发 `AskError`，强制请求人类确认。
4. **执行**：运行工具的实际逻辑。
5. **后置钩子**：结果改写与审计记录。

## 应用工具与内置通用工具

AIH 的工具来自两个来源：

- **应用工具**：由 `AppAdapter` 的 actions 提供（参见 [第 8 章](ch08)）。
- **内置通用工具**（`cli/src/dev-tools.ts` + `general-tools.ts`）：`list_dir`、`read_file`、`write_file`、`run_cmd`、`edit`、`glob`、`grep`、`webfetch`、`websearch`、`task`、`best_of_n`、`question`、`remember`、`load_skill`、`todo`。

当应用工具与内置工具同名时，**应用工具优先**。

## 并行只读执行

为提升效率，AIH 支持并行只读调用（F#29）：连续的只读工具调用会并发执行，上限为 `AIH_TOOL_CONCURRENCY`（默认 4）。写操作始终串行执行。所有结果按原始调用顺序返回，由 `agent-loop.ts` 中的 `mapConcurrent` 实现。
