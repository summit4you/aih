# 第12章 CLI 与 TUI

AIH 提供了功能完整的命令行界面（CLI）和终端用户界面（TUI），覆盖从交互对话到后台服务的全场景。本章梳理命令体系、TUI 交互与模式切换。

## 命令体系

AIH 的命令入口在 `cli/src/index.ts`，由 `main` 函数分发到各子命令：

- **aih / aih chat**：启动交互式 TUI 对话
- **aih run**：非交互式执行
- **aih tools**：列出可用工具
- **aih describe**：查看工具详情
- **aih config**：管理配置
- **aih session**：会话管理（`list`、`show`、`export`、`fork`、`checkpoint`、`restore`）
- **aih skills**：技能管理（`list`、`find`、`install`、`show`）
- **aih stats**：查看统计信息
- **aih serve** / **aih attach**：headless 服务与连接
- **aih coverage** / **aih quality**：覆盖率与质量报告
- **doctor --fix**：自动修复常见问题

裸命令 `aih` 需要 TTY 环境才能启动交互对话，否则打印帮助信息。

## TUI 界面

TUI 实现位于 `cli/src/tui.ts`，采用 opencode 风格设计。快捷键定义在 `cli/src/keybinds.ts` 和 `tui.json` 中。

核心交互元素包括：

- **Tab / `/mode build`**：在 build 和 plan 模式间切换
- **`/usage`**：查看 token 用量
- **`/goal`**：设置或查看当前目标
- **Context 面板**：显示成本（`$x`）、token 速率（`N tok/s`）
- **状态栏**：显示当前模式和连接状态

Markdown 表格在 TUI 中原生渲染，CJK 字符和 emoji 的宽度通过 `string-width` 正确计算，确保对齐。

## 开发模式语义

`--dev` 和 `--no-dev` 标志控制工具集的可用范围：

- **aih chat**：默认启用本地工具集（`--no-dev` 可关闭）
- **aih run / aih workflow / aih tools**：本地工具集默认关闭，需要显式 `--dev` 开启

这一设计确保生产环境不会意外暴露开发工具。交互式对话更宽松，自动化执行更严格——符合最小惊讶原则。

## 非 TTY 分发

当 `aih chat` 在非 TTY 环境运行时，自动退化为 headless 模式。`aih serve` 启动 HTTP 服务端，`aih attach` 连接到已有服务。这使得 AIH 可以嵌入 CI/CD 管道、远程服务器和容器环境。

## 小结

AIH 的 CLI 和 TUI 设计体现了"渐进式复杂度"：简单命令开箱即用，高级功能通过标志和子命令逐步解锁。无论你是终端新手还是效率专家，都能找到合适的交互方式。更多权限相关配置可参考 (../permissions)，核心机制详解见 (ch09)。
