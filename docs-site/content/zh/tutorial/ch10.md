# 第10章 快照与文件系统

文件操作是 AI 助手最高频的交互。AIH 在"能做事"和"不搞砸"之间取得了精心设计的平衡——通过快照系统、沙箱隔离和精细的文件工具权限实现。

## 会话快照机制

AIH 采用 **追加日志（append-only log）** 模型管理会话状态。每次操作产生一个 `SessionEvent`，形成可重放的时间线。核心操作包括：

- **Checkpoint**：保存当前状态快照（`cli/src/sessions.ts`）
- **Restore**：回滚到最近的检查点
- **Fork**：基于当前状态创建分支，形成会话树
- **Recovery**（`recovery.ts`）：扫描截断的日志尾部进行恢复

`coverageDigest` 机制确保投影数据的可验证性——快照不仅是状态复制，更是审计基础。你可以随时审查 AI 做了哪些变更。

## 沙箱后端

文件写入操作可通过 **SandboxBackend**（`cli/src/sandbox.ts`）隔离执行。支持三种后端：

| 后端 | 说明 |
|------|------|
| `local` | 默认，直接在本地执行 |
| `bwrap` | 使用 Bubblewrap 沙箱隔离 |
| `remote` | 远程沙箱执行 |

通过环境变量 `AIH_SANDBOX` 或工具调用的 `sandbox` 参数指定。沙箱不影响只读操作——读取始终安全。

## 文件工具集

AIH 提供一组精心设计的文件操作工具：

- `read_file`：读取文本文件，64KB 上限，支持行偏移
- `write_file`：创建或覆盖文件
- `edit`：精确字符串替换（歧义时需用 `replace_all`）
- `list_dir`：列出目录内容
- `glob`：按模式查找文件
- `grep`：正则搜索文件内容

权限规则很直观：**所有读取自动允许，所有写入需要确认**。这是最小权限原则的体现——AI 可以自由查看，但修改需要你的许可。

## 环境过滤与凭证保护

`cli/src/env-policy.ts` 在启动子进程时执行严格的环境变量过滤。以下类型的关键字会被剥离：

- 包含 `KEY`、`TOKEN`、`SECRET`、`PASSWORD` 的变量
- 所有 `AIH_*API*` 核心凭证

凭证实行所有者隔离——密钥仅发送到所有者端点。这确保即使 AI 工具调用外部服务，你的敏感信息也不会泄露。

## 小结

文件系统是 AIH 最危险也最有价值的能力。快照提供后悔药，沙箱提供隔离墙，权限模型提供审批关卡，环境过滤提供数据防火墙。层层防护让你放心让 AI 工作。了解更多快照细节可参考 (ch09) 的权限上下文。
