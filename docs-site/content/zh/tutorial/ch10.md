# 第10章 快照与文件系统

文件操作是 AI 助手最高频的交互。AIH 在"能做事"和"不搞砸"之间取得了精心设计的平衡——通过快照系统、沙箱隔离和精细的文件工具权限实现。

> **先给小白的一句话**：AI 读你盘上的文件，就像一位**有"后悔药 + 隔离手套"的助手**——改了能回滚（快照）、捏住敏感文件时戴着隔离手套（沙箱）、想动你的文件还得先问你（权限）。三者合起来，让你敢放心让 AI 干活。

## 会话快照机制

AIH 采用 **追加日志（append-only log）** 模型管理会话状态。每次操作产生一个 `SessionEvent`，形成可重放的时间线。核心操作包括：

- **Checkpoint**：保存当前状态快照（`cli/src/sessions.ts`）
- **Restore**：回滚到最近的检查点
- **Fork**：基于当前状态创建分支，形成会话树
- **Recovery**（`recovery.ts`）：扫描截断的日志尾部进行恢复

`coverageDigest` 机制确保投影数据的可验证性——快照不仅是状态复制，更是审计基础。你可以随时审查 AI 做了哪些变更。追加式事件流与分叉/回滚的实现细节，见 [第 4 章「会话系统」](ch04)——那里有完整的示意图。

> **一句话记牢**：快照不是"把文件复制一份存起来"，而是"保住那条能让状态重播的事件前缀"。回滚 = 从存档点重新分叉。

## 沙箱后端

文件写入操作可通过 **SandboxBackend**（`cli/src/sandbox.ts`）隔离执行。支持三种后端：

| 后端 | 说明 |
|------|------|
| `local` | 默认，直接在本地执行 |
| `bwrap` | 使用 Bubblewrap 沙箱隔离 |
| `remote` | 远程沙箱执行（默认主机来自 `AIH_REMOTE_HOST`） |

沙箱后端的**选择优先级**是（`cli/src/sandbox.ts`）：

1. 每次调用 `run_cmd` 的 `sandbox` 参数
2. `AIH_SANDBOX` 环境变量（`local` / `bwrap` / `remote` / 自定义注册名）
3. 默认 `local`

> **沙箱是什么？** 它是给 `run_cmd` 换的"执行房间"：`bwrap` 把工作目录设成只读、只留 `/tmp` 可写，最小化权限地跑命令；`remote` 则把命令送到远程主机(ssh)执行。无论哪种，**只读操作始终本地安全**——看一眼不碰，不需要隔离。

## 文件工具集

AIH 提供一组精心设计的文件操作工具：

- `read_file`：读取文本文件，64KB 上限，支持行偏移
- `write_file`：创建或覆盖文件
- `edit`：精确字符串替换（歧义时需用 `replace_all`）
- `list_dir`：列出目录内容
- `glob`：按模式查找文件
- `grep`：正则搜索文件内容

权限规则很直观：**所有读取自动允许，所有写入需要确认**。这是最小权限原则的体现——AI 可以自由查看，但修改需要你的许可。这套"读=绿卡、写=询问"的判定机制，正是 [第 9 章「权限控制系统」](ch09) 里三档权限在文件工具上的具体应用。

## 环境过滤与凭证保护

`cli/src/env-policy.ts` 在启动子进程时执行严格的环境变量过滤。以下类型的关键字会被剥离：

- 包含 `KEY`、`TOKEN`、`SECRET`、`PASSWORD` 的变量
- 所有 `AIH_*API*` 核心凭证

凭证实行所有者隔离——密钥仅发送到所有者端点。这确保即使 AI 工具调用外部服务，你的敏感信息也不会泄露。

## 小结

文件系统是 AIH 最危险也最有价值的能力。快照提供后悔药，沙箱提供隔离墙，权限模型提供审批关卡，环境过滤提供数据防火墙。层层防护让你放心让 AI 工作。关于工具执行的守卫管线，见 [第 5 章「工具系统」](ch05)。
