# The Skill System

Skills are the lightest form of extension in AIH—essentially just a Markdown file. No code required. Anyone can create, share, and use skills to enhance AI capabilities in specific scenarios.

## What Is a Skill?

A skill is a `SKILL.md` file with two parts:

- **YAML frontmatter**: declares `name` (skill name) and `description` (short summary)
- **Markdown body**: the full skill instructions, injected into context as part of the system prompt when loaded

AIH loads skills via the `load_skill(name)` tool call. The first call returns the full text; a second call for the same skill within the same session returns only a summary—this is the **SkillLoadTracker deduplication mechanism** (CC#52), preventing redundant context consumption.

## Three-Tier Loading

Skill lookup follows a three-tier priority where higher-priority skills shadow lower ones of the same name:

| Priority | Source | Path |
|---|---|---|
| Highest | Project-level | `.aih/skills/` |
| Middle | User-level | XDG `~/.aih/` |
| Lowest | Built-in | AIH installation directory |

This means a team can place custom skills in a project repository to override global or built-in skills of the same name, enabling project-level customization.

## BM25 Auto-Suggestion

AIH includes a built-in skill suggestion engine powered by the **Okapi BM25** algorithm (implemented in `cli/src/bm25.ts`). As conversation progresses, the `suggestSkills` function ranks all available skills against the current dialogue and automatically recommends the most relevant ones.

Core BM25 parameters are **K1=1.5** and **B=0.75**, with **CJK bigram** tokenization for multilingual support. Recommended skills are written into the context skill roster, but the roster is strictly capped at **2% of the context budget** (`withSkillRoster`), ensuring the suggestion mechanism itself doesn't consume excessive context.

## Bundled Skills

AIH ships with the following practical skills, ready to use out of the box:

- **app-tour** — guided tour of AIH features
- **batch-ops** — batch operation patterns
- **code-review** — code review workflow
- **find-skills** — discover and install skills from the community ecosystem
- **loop-design-check** — loop design verification
- **tui-design** — TUI interface design guide
- **web-design-guidelines** — web design conventions
- **session-report** — session report generation

Each built-in skill can be loaded directly with `load_skill("skill-name")`.

## Future Direction

The skill system's roadmap includes **skill-creator** (an assistant for building new skills) and **self-evolving skills**—AI that automatically optimizes and generates new skills based on usage patterns. These planned features reflect the system's trajectory toward lower barriers and greater intelligence.
