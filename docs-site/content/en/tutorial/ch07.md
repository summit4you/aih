# The Provider Layer

AIH adapts to multiple large language models through a unified Provider layer, keeping the upper logic free from backend-specific differences.

## The LLMAdapter Interface

The core LLM adaptation interface is defined in `core/src/seams/llm.ts` (`LLMAdapter`). Key implementations include:

- **llm-openai.ts**: OpenAI-compatible protocol with SSE streaming and automatic retries.
- **llm-sse.ts**: low-level SSE utilities—`consumeSSEStream` consumes the stream, `parseFrame` parses frames, `StallError` represents stream stalls, and `classifyProviderError` classifies error types.

## Model Resolution

Model configuration is resolved through `resolveLlm` and `loadModelCatalog` in `cli/src/config.ts`, reading in this priority order:

1. Environment variables `AIH_API_KEY` (API key), `AIH_MODEL` (model name), `AIH_BASE_URL` (endpoint URL).
2. Corresponding fields in the configuration file.
3. The `--mock` flag for offline simulation mode.

## Model Metadata

`cli/src/model-metadata.ts` maintains a snapshot of model data from models.dev, including context window sizes, capability tags, and other information for each model. The provider list is also managed in this module.

## Cost and Throughput Tracking

`cli/src/cost.ts` provides comprehensive cost and throughput analysis:

- **DEFAULT_PRICES**: default pricing for each model.
- **resolvePrice**: resolves the price for a specific model.
- **costForUsage**: calculates cost based on actual token usage.
- **aggregateUsage**: aggregates usage across multiple turns.
- **tokensPerSecond**: computes model response throughput (TPS).

These metrics are displayed in real time in the TUI Context panel and can also be accessed via the `/usage` command or `aih stats`. See [Ch.4](ch04) for related session details.
