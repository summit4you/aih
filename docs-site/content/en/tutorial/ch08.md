# MCP & Integration Shapes

AIH supports multiple integration shapes—from MCP external services to CLI commands to embedded SDKs—adapting to different usage scenarios.

## The L0 AppAdapter Contract

The `AppAdapter` (`mcp-server/src/app-adapter.ts`) is the core contract for integrating AIH with external applications. It consists of three parts:

- **descriptor**: application description information.
- **context(query)**: returns current context based on the query.
- **actions**: a set of operation definitions, each containing `kind` (read/write), `permission` (allow/ask/deny), `parameters` (Zod schema), and a `run` execution function.

`APP.md` serves as the source of truth for the AppAdapter. The `TodoAppAdapter` is an example that implements full read/write operations for a Todo application.

## Three Integration Shapes

### MCP External Service

Mount `mcp-server/dist/index.js` into external clients like opencode, codex, or claude, interacting through the MCP protocol. Ideal for teams already using AI coding tools.

### CLI

Use `aih`, `aih run`, or `aih chat` directly for interactive sessions. This is the simplest way to get started—see [Ch.7](ch07) for model configuration details.

### Embedded SDK

Use `AgentLoop` and `ToolRegistry` from the `@aih/core` package to build agents programmatically:

```typescript
const registry = new ToolRegistry();
registry.register({ name, description, kind, permission, run });
// Pass registry to AgentLoop
```

Best suited for deeply customized integrations.

## Write-Ops Confirmation

AIH enforces safety confirmation for write operations: in TTY terminals, a `[y/N]` prompt is shown; in non-TTY environments (e.g., CI), the `--yes` flag must be passed to execute. See [Ch.5](ch05) for the tool guard pipeline.

| Shape | Use Case | Entry Point |
|-------|----------|-------------|
| MCP External Service | Existing AI coding tools | `mcp-server/dist/index.js` |
| CLI | Quick interaction & scripting | `aih` / `aih run` / `aih chat` |
| Embedded SDK | Deep customization & integration | `@aih/core` |
